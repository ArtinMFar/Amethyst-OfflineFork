# Prebuilt APK

`Amethyst-Offline-debug.apk` split into 5 parts, since GitHub rejects files over 100 MB.

1. Download all 5 `Amethyst-Offline-debug.7z.00*` files into the same folder.
2. Open `Amethyst-Offline-debug.7z.001` with ZArchiver (Android) or 7-Zip (PC) and extract.
3. Install `Amethyst-Offline-debug.apk` (appears as "Amethyst (Debug)").
